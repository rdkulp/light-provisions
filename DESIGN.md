# Brand overview
Light Provisions sells handmade candles, Japanese lighters, incense, and considered objects for the home. Its audience values useful objects, warm materials, and independent craftsmanship.

# Design thesis
Warm product photography, restrained serif headings, and practical shopping layouts carry the fire.

# Colors
Keep the existing color schemes unchanged. Scheme 2 uses #f1efee for surfaces, #a15736 for headings, and #414042 for body text. Scheme 8 uses #c9c2af for surfaces, #333333 for headings, and #4b4b4b for body text. Scheme 4 uses #3a5048 for deep green surfaces. Use the theme's color tokens and scheme controls.

# Typography
Use the theme's existing font variables and presets. Current settings specify serif headings, Instrument Serif accents, Inconsolata subheadings, and Source Code Pro body font. The theme also supplies overrides, so inherit its rendered type rather than replacing families. Heading sizes are 72, 48, 32, 24, and 16px; paragraph setting is 18px. Preserve existing line-height, weight, and tracking.

# Spacing and composition
Use native section widths and the theme's page gutters: 16px mobile, 40px desktop. Text regions use the native content width. Image grids use page width, 24px desktop column gaps, and 16px mobile gaps. Keep product images square and corners unrounded. Preserve global spacing and button settings.

# Components
Header and footer stay native. Product and category links show store photography above a clear title, short description, and visible shopping label. Keep one keyboard-focusable link per card. Buttons use existing theme styles, with the current 12px radius. Inputs and menus remain native.

# Dos and Don'ts
Use actual store products, collections, and resource pickers. Keep text selectable and editable. Make shopping destinations obvious. Preserve sale terms. Do not introduce new global fonts, palettes, decorative effects, or unrelated template changes.

# Motion philosophy
Preserve existing theme behavior. New shopping tiles need no animation. Use clear hover and keyboard focus states.
